## Findings reported by local Codex D8-B execution
1. All 25 formal run coordinates, 6,000 planned/actual message injections (240 per run), and 100 churn/recovery observations were reconstructed. No confirmed frozen-protocol violation was identified. All original observations were retained.
2. Planned message-grid deviation was reported as 0 seconds; maximum actual injection-start lateness was 7.535934 milliseconds. Injection-scheduler compliance alone cannot establish neighbor-state convergence or successful dissemination.
3. The `18 s` setting belongs to **run-level settling after message injection**, not to a per-rejoin recovery deadline. The existing recovery calculation can seek a later full-delivery message without stopping at the next churn. The current table assigns a nominal 18 s value to unrecovered observations although opportunity windows may differ; the local audit reports 20 final-event unrecovered observations with fewer than 18 seconds of later injection opportunities. Treat this as a metric-definition/observation-window limitation, not as a runtime protocol defect unless further independent evidence establishes one.
4. In seed44/Gossip the event-1-to-message-m77-full-delivery interval was reported as **27.438531 s**. Event 2 intervened, and `m77` also satisfies event 2 at **2.982053 s**. This is not an isolated churn-event or pod-ready recovery time. Do not call it a violation of an 18 s per-event deadline.
5. Across 100 event anchors, local availability changes were observed in 70, forwarding attempts to/from target in 68, and new target deliveries in 56. No explicit **cluster-wide neighbour membership convergence** records were available. These event counts do not prove that stale peer state caused low delivery; timing impact remains plausible, not established as the sole cause.
6. D8-focused tests reportedly passed 17/17. The broader 152-test regression run was not fully green due to two missing dependency/import errors (`grpc`; system Python also lacked `yaml`). This is an offline verification-environment limitation; full-suite pass must not be claimed.
